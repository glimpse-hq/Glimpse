# Localization

For translation or locale review, use [the localization skill](../skills/localize/SKILL.md). The orchestrator delegates scoped locale batches to low-cost subagents, then reviews and validates them locally. This replaces Lokalise as the default translation workflow. The legacy `locale:pull-task` command is not part of this workflow; do not run it over agent-reviewed catalogs unless the user explicitly requests an import.

Strings use `t({ id, message })`. Changing the `message` of an existing id does not update the catalog: extract keeps the old English `msgstr`, and the app keeps showing the old text while every check passes.

When you edit an existing `message`:

1. Update its `msgstr` in `src/locales/en/messages.po`.
2. Identify affected translations in other locales, including non-empty translations of the previous English. When translation is in scope, update them using the localization skill. Otherwise report the IDs needing translation; blank stale English copies, but preserve existing non-English translations for review rather than deleting them blindly.
3. `bun run lingui:extract`, `bun run lingui:compile`, then confirm the text in `src/locales/en/messages.js`.

`extract --clean` deletes the translations of unreferenced ids. If restoring deleted code, recover its catalog entries from the matching revision while preserving unrelated locale edits.

## Native strings and generated catalogs

- `supported-app-locales.json` is the shipped-locale source of truth for Lingui, the frontend, and the Rust build. Do not maintain another locale list.
- Native menu messages are declared in `src/shared/lib/nativeMenuStrings.ts`. `src-tauri/build.rs` reads `native.*` entries from the PO catalogs into a generated Rust catalog consumed by `native_i18n.rs`. Update the declaration and catalogs together; do not hand-edit build output.
- `src/locales/*/messages.js` is compiled output. Regenerate it from PO files rather than editing it directly. Review extraction output so a small copy edit does not silently remove unrelated translations.
